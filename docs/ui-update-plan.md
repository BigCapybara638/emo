# Обновление интерфейса

Используем существующий WPF-интерфейс и предоставленное руководство: Calibri,
белый фон, #D2F6E7, акцент #70B2AF, остаток <=3 — #FF8080.
Логотип и иконка сохраняются без изменения пропорций.

- [x] Карточки: выделить изображение, сведения и итоговую цену; убрать повторяющиеся подсказки.
- [x] Добавить надпись «Поиск» внутри пустого поля.
- [x] Убрать прямое оформление из карточки; оставить корзину и подтверждение заказа.
- [x] Автоматически сохранять выбранную дату существующего заказа только администратору, не записывать дату при загрузке формы.
- [x] Оставить кнопку добавления доступной при превышении остатка; проверять количество при нажатии с сообщением об ошибке.
- [x] Переименовать кнопку изменения количества в «Применить количество».
- [x] Добавить совместные фильтры в заголовки столбцов обеих таблиц, сохранить сортировку и общий итог заказа.
- [x] Скрыть столбец скидки, сохранив итоговую цену и данные для транзакций.
- [x] Обновить регрессионные проверки, собрать .NET 10, проверить интерфейс и БД.

Проверка: 72 успешные регрессии на .NET 10 и отдельной базе
`emo_validation_schema_20261112`; Release-сборка прошла без ошибок.
При сборке NuGet сообщает NU1900: источник сведений об уязвимостях недоступен.

Выбрано развитие существующего DataGrid без сторонней библиотеки: фильтры
доступны непосредственно в заголовках. Новая библиотека для двух таблиц не нужна.
Цена оформленного заказа остаётся зафиксированной при оформлении: пользователь
видит уже рассчитанную цену с учётом скидки, без отдельного столбца процентов.
